# Jules MCP Server (`jules-mcp`)

Universal Model Context Protocol (MCP) server for Google Jules Cloud Agent with 100% native REST API coverage and automated multi-account load balancing.

## Features & Capabilities

- **100% API Discovery Coverage**: Complete support for sessions, activities, plans, bash logs, patches, media artifacts, and sources.
- **Multi-Account Rotation & Failover**: Pool multiple Google accounts (e.g. 3 accounts = 45 daily tasks) with automatic round-robin and instant failover on rate limits.
- **Cloud Auto-PRs**: Automatically create branches and GitHub Pull Requests directly from Google Cloud upon completion.
- **Step-by-Step Plan Approval**: Inspect structured plans and approve them before Jules modifies codebase files.
- **Sandbox Terminal Logs**: Real-time inspection of commands, exit codes, and stdout/stderr from Google's cloud execution sandbox.
- **Artifacts Extraction**: Direct access to unidiff patches, suggested commit messages, and visual media (diagrams/screenshots).
- **Batch Dispatches**: Launch multiple tasks across different repositories in parallel with automatic account distribution.

## Tool Reference (16 Tools)

1. `jules_list_sources` - List all connected repositories, active branches, and default branches across accounts.
2. `jules_get_source` - Get detailed metadata and branch list for a specific repository.
3. `jules_create_task` - Dispatch a coding task with starting branch, working branch, auto PR, plan approval, and secrets injection options.
4. `jules_batch_dispatch` - Dispatch multiple tasks across different repositories simultaneously.
5. `jules_list_sessions` - List and filter sessions by state (`IN_PROGRESS`, `AWAITING_PLAN_APPROVAL`, `AWAITING_USER_FEEDBACK`, `COMPLETED`, `FAILED`), repo, or limit.
6. `jules_get_session` - Retrieve full status, PR URL, git diff, Jules Web URL, and execution timeline.
7. `jules_get_plan` - Extract the step-by-step plan generated by Jules.
8. `jules_approve_plan` - Approve an execution plan to unblock code implementation.
9. `jules_reply_feedback` - Reply to Jules when paused in `AWAITING_USER_FEEDBACK` or provide follow-up steering.
10. `jules_get_patch` - Extract clean unidiff patch and suggested commit message.
11. `jules_inspect_bash_logs` - View raw bash sandbox commands, exit codes, and execution output.
12. `jules_get_media_artifacts` - Retrieve screenshots, diagrams, or visual media produced by Jules.
13. `jules_archive_session` - Archive or unarchive a session.
14. `jules_delete_session` - Permanently delete a session.
15. `jules_sync_prs` - Extract completed patches, verify locally with tests, and open GitHub PRs via `gh`.
16. `jules_pool_status` - Real-time quota, health, active and completed session counters across all accounts.

## Configuration

### Multi-Account Pool (`~/.config/jules/keys.json`)
```json
{
  "accounts": [
    {
      "name": "account1@gmail.com",
      "key": "AQ.Ab8...",
      "active": true
    },
    {
      "name": "account2@gmail.com",
      "key": "AQ.Ab8...",
      "active": true
    }
  ]
}
```

### Claude Code (`~/.claude/settings.json`)
```json
{
  "mcpServers": {
    "jules": {
      "command": "jules-mcp",
      "args": []
    }
  }
}
```

### Cursor / Windsurf (`mcp.json`)
```json
{
  "mcpServers": {
    "jules": {
      "command": "node",
      "args": ["/root/projects/jules-mcp/dist/index.js"]
    }
  }
}
```
